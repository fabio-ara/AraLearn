# Abrir com AraLearn no Android

No Android, o AraLearn pode receber arquivos compartilhados por outros apps.

Esse recurso permite que um PDF, DOCX ou outro material compatível entre no fluxo do app como fonte de estudo, referência para organização ou projeto a importar.

## Como funciona

O usuário escolhe um arquivo em outro app e usa a ação de compartilhar com o AraLearn. O app recebe esse arquivo e o trata como entrada possível para o projeto.

A partir daí, o material pode ser usado de formas diferentes, conforme o tipo de arquivo e o fluxo escolhido.

## Quando é útil

Esse recurso é útil quando o estudo começa fora do AraLearn.

Exemplos:

- abrir uma apostila em PDF no celular;
- enviar um DOCX para servir de base a uma lição;
- aproveitar um arquivo recebido por mensagem;
- importar um projeto salvo anteriormente;
- transformar anotações em fonte para uma trilha.

## Por que isso importa

Muitas sessões de estudo começam em condições móveis: no transporte, entre atividades, durante uma aula ou a partir de um arquivo recebido de última hora.

Permitir que o AraLearn receba material por compartilhamento reduz o atrito entre encontrar uma fonte e organizá-la em percurso.

## Limitações

Receber o arquivo não garante aproveitamento perfeito.

A qualidade do resultado depende de:

- formato do arquivo;
- qualidade da extração textual;
- presença de imagens ou tabelas complexas;
- clareza do material original;
- fluxo escolhido pelo usuário depois da importação.

Quando a extração não for suficiente, o usuário deve revisar e corrigir a orientação gerada.

## Privacidade

O recurso foi pensado para operar sobre o material no próprio dispositivo.

Compartilhar um arquivo com o AraLearn não significa criar sincronização contínua com uma fonte externa. Operações com IA remota, quando usadas, dependem do serviço configurado pelo usuário.
