Citation Style Language styles and locales
License: Creative Commons Attribution-ShareAlike 3.0 Unported (CC-BY-SA-3.0).
See CC-BY-SA-3.0.txt in this directory. The original XML files preserve all
authors, contributors, attribution, source links and license notices.
Packaging modification by AraLearn, 2026-09-05: XML source is encoded as
JavaScript string constants for offline module loading. These generated
style/locale strings remain available under CC-BY-SA-3.0. The original XML files
remain unchanged in src/bibliography/upstream.
Additional UFRGS adaptation, aralearn-abnt-elocation-v1 (2026-09-05): the generated
style prints an article's electronic location (CSL number) when no page range is
provided. It does not label an electronic location as a page. The exact patch
is recorded in scripts/buildBibliographyVendor.mjs.
Additional UFRGS adaptation, aralearn-abnt-access-punctuation-v1 (2026-09-05):
the webpage and report branches use the access macro's existing punctuation,
without appending a second period when the access date is absent. No date is
inferred or inserted. The exact patch is recorded in the same script.
Additional UFRGS adaptation, aralearn-abnt-empty-separator-v1 (2026-09-05):
the report branch omits the publisher's extra separator when intermediate
metadata is absent; the generic branch separates the date only when publication
metadata requires it. No content or dates are supplied. The exact conditional
patch is recorded in scripts/buildBibliographyVendor.mjs.
