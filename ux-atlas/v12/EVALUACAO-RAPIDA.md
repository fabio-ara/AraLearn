# Avaliação rápida — 10 minutos

Não é necessário percorrer 101 telas para decidir se a arquitetura está coerente. Use cinco percursos:

1. **Estudo → Curso → Módulo → Lição → Microssequência → Unidade** — contexto, progresso, voltar e subir nível.
2. **Autoria → Meus cursos → Inspeção → Inspeção · Unidade** — conteúdo em primeiro plano; Fontes, Observação, Editar, Auditar e ChatGPT como ações irmãs.
3. **Autoria → Curso → Fontes → Detalhe da Fonte → Editar Âncora / PDF** — proveniência e operações progressivas.
4. **Pesquisa → Visão do recorte → Definição da métrica → Fatos → Detalhe do fato** — gráfico + tabela + denominador + limites + retorno ao objeto.
5. **Pesquisa → Variantes → Criar → Comparação → Diferenças → Variante** — parâmetros/componentes e diferenças sem sugerir efeito sobre aprendizagem.

Depois abra **Cobertura**. Cada capacidade `backend atual` deve possuir ao menos uma tela/estado. `Efeitos sobre estudantes` deve permanecer futuro.
