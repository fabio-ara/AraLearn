# Atlas visual do AraLearn

A versão corrente desta branch é a **v11**, em [`v11/`](./v11/). A **v10** fornecida como baseline de continuidade está preservada em [`v10/`](./v10/), identificada também pelo SHA-256 do ZIP original.

A v11 é uma evolução direta da v10: mantém as 59 telas anteriores e acrescenta 19 superfícies/estados para tornar a cobertura do backend verificável, especialmente em Autoria, Pesquisa/Analytics, Variantes, componentes, Fontes e Pessoas.

Abra `index.html`: ele redireciona para `v11/index.html` preservando o hash. Para validar a edição versionada, execute `node v11/validate.mjs`.
